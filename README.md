# PHP STEP — PHP8初級 学習アプリ（試作版）

Python / Flask / JavaScript / Peewee / SQLite で作る、Android向け学習アプリです。
PHPコードは教材として表示するだけで、PHPの実行環境は不要です。有料AI APIは使いません。

## 起動する

Cursorでこのフォルダを開き、ターミナルから次を実行します（Windows、Python 3.13）。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.\.venv\Scripts\python.exe app.py
```

すでに `.venv` がある場合、最初の2行は不要です。
ブラウザで http://127.0.0.1:8000 を開きます。停止はターミナルで Ctrl+C。
PythonのPATHが通っていない場合は、インストール済みPythonの実行ファイルを指定します。
Node.jsはJavaScriptのテストにだけ使用し、アプリ起動には不要です。

## 今できること

- 11分野・100問のオリジナル対策問題（単一選択・複数選択）
- 1回5問、分野別練習、ランダム10問チェック
- 自信あり／迷った／わからないの記録と、苦手を優先する復習
- 回答済みの途中学習を再開、復習の印、問題と質問のコピー
- やさしい説明・処理の順序・公式マニュアルの参照リンク
- 問題を解く→解説を読む→自信を記録する学習フロー（10問チェックは解説を最後に表示）
- 回答後に開ける基礎のミニ解説と別のコード例
- 「詳しく見る」で全100問のコード各行と全選択肢の理由を表示
- 今日間違えた・迷った問題をまとめて復習、翌日以降の自動出題、苦手一覧から個別復習
- 質問ノートに回答時の選択肢・自信・メモを保存し、まとめてコピーしてチャットで質問
- 試験予定日と目標問題数の変更、JSONバックアップの書き出し・読み込み
- 端末内保存と、同じブラウザ用のサーバーバックアップ（Peewee＋SQLite）
- ホーム画面追加とオフライン用のPWA構成。Android実機での確認は公開後に行う

100問は公式の出題範囲を参考に独自作成した練習問題です。公式問題や過去問ではなく、本試験と同じ難易度・出題の網羅を保証するものではありません。作成方針と検証内容は `PRACTICE_CONTENT.md` に記載しています。
参考サイト https://mogishiken.jp/ は確認済みです。掲載問題の転載はしていません。本番40問・60分の形式は未実装です。
無料の質問機能は事前作成の補足解説です。自由入力にAIが回答する機能はありません。

## データと復習

履歴は localStorage に保存し、通信可能なときに `/api/state` へ保存します。
ブラウザを識別する署名付きCookieで、他のブラウザの履歴と分離します。
別端末のログイン・アカウント同期機能はありません。履歴ファイルで移行してください。
Cookie削除後はサーバー側の以前の履歴へアクセスできません。バックアップを残してください。
サーバーと端末の履歴が競合した場合は、自動上書きを止め、設定画面で選べます。
`instance/` にDBと署名用キーを作成します。公開ディレクトリに置かず、Gitへ追加しないでください。

不正解・自信なしは優先復習。自信ありの連続正解で次の復習を1日→3日→7日へ広げます。
「あとで復習」の印は自動では消えません。苦手が多くても通常の5問には新問を1問混ぜます。
未送信の選択肢は保存せず、回答確定時に保存します。質問は「質問ノートに保存」を押して保存します。
質問ノート画面でメモを編集すると自動保存します。JSONバックアップとサーバー保存にも質問ノートを含めます。
まとめてコピーした内容は自動送信しません。このチャットなどに貼り付けて質問してください。
「今日の振り返り」は端末の日付を使い、今日の最終回答が不正解・自信なし、または復習の印がある問題を選びます。

## ファイルの役割

- `app.py`：Flaskの配信・履歴API・Peeweeモデル・入力検証
- `data/questions.json`：問題と分野のデータ（ここを編集して追加）
- `templates/index.html` と `static/`：画面・採点・復習・同期・オフライン
- `wsgi.py`：公開先から読み込む入口
- `tests/`：復習・採点・保存・ブラウザ間の分離・不正データのテスト

問題や画面を更新するときは `static/sw.js` の `CACHE` のバージョンも増やしてください。
既存のタブを全て閉じて再度開くと、新バージョンへ切り替わります。
問題IDは履歴に使うため、既存のIDを他の問題へ再利用しないでください。

## テスト

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py"
node --test tests/core.test.mjs
```

## Androidからの利用・無料での公開

PCの `127.0.0.1` は、そのPC自身のアドレスです。スマホからは直接開けません。
実用版はFlask対応のHTTPS公開先に配置し、Chromeで開いてホーム画面へ追加します。
初回の読み込み完了後、保存済み問題はオフラインで使えます。マニュアル閲覧は通信が必要です。
公開はまだ行っていません。無料候補のPythonAnywhereは、確認時点で1アプリ・1 worker・512MiB・1か月の有効期限などの制限があります。
利用条件・期限延長手順を確認してから採用します。「無制限・永久無料」を保証するものではありません。
Flaskのデバッグサーバーをインターネットに公開せず、公開先のWSGIを使用してください。
HTTPS公開時は `PHP_STEP_HTTPS=1` を設定します。SQLiteと署名用キーを永続保存できる公開先を選びます。
ローカル用のWaitressは既定でPC内のみに接続を許可しています。
